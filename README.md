# The Attention Edit

A responsive, frontend-only curated content website.

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.

## Included
- Homepage with custom inline SVG vector illustrations
- Six playful content categories
- Curated external resources with category filtering and search
- Save-for-later shortlist using browser localStorage
- Responsive mobile navigation and subtle reveal animations

## Fonts
The CSS is prepared for `Handpicked Seashells`, `Aneto Skyline`, and Aptos. If you have licensed `.woff2`, `.woff`, `.ttf`, or `.otf` font files for the first two, put them in a `fonts/` folder and add `@font-face` declarations at the top of `style.css`. Until then, the site uses Space Grotesk and a cursive fallback. Aptos is used when installed, with DM Sans as a fallback.
